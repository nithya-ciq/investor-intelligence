Landmines to add to HANDOFF §10 (new techniques this sweep proved out)

  • Vendor alt text lies. Leadbeam's logo wall has 3 of 15 alt attributes wrong — including a phantom "ClearCross" that is actually ClassPass. A text-only scrape would have invented a customer that doesn't exist. Download and visually inspect logo images. (Same class as the Overproof Swiper-carousel miss in v5.)
  • CMS blog dates are unusable. Every Leadbeam post carries a bulk-stamped datePublished from a CMS migration — the beverage post reads "July 2026" but shipped Sept 2025. Off by ten months. Use Wayback CDX first-seen instead.
  • CDN ObjectID timestamps date site changes to the second. Webflow CDN filenames are MongoDB ObjectIDs whose first 4 bytes are the upload epoch — this dated every Leadbeam site change with no reliance on Wayback coverage.
  • Trade press blocks automated fetches. thespiritsbusiness.com, brewbound.com, distilledspirits.org, crunchbase.com and pitchbook.com all return 403. Use curl with a browser UA and paragraph extraction — which also recovers exact post-publish-date metadata.
  • Naive grep -i manufactures fake findings. This sweep caught and discarded: Provi → "provide" · IRI → "spirits" · Snowflake → FontAwesome fa-snowflake-o · Pernod → "wrapperNode" · Tito → "competitors". Four fake data partners avoided. Use word boundaries.
  • Sunbiz and EDGAR full-text are Cloudflare-gated at times; EDGAR's API needs a control query (searching a known-present term) to prove a zero result is a real negative rather than a broken query.
